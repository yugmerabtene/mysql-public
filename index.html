MySQL Cluster

Administration et exploitation d'un cluster NDB sur 3 VM isolées

Parcours de formation : MySQL Cluster — Administration et exploitation

Public : administrateurs système et bases de données (niveau débutant à intermédiaire)

Durée : 5 jours

Infrastructure : 3 VM Ubuntu Server 24.04 LTS sur réseau isolé vboxnet0 192.168.56.0/24

Architecture : 1 nœud de gestion (NodeId 1) + 2 nœuds de stockage (NodeId 2 et 3) + 2 nœuds SQL (NodeId 4 et 5)

Contenu : Chapitres 1 à 5 — Introduction, installation, architecture, administration, supervision, maintenance, optimisation, réplication, sécurité

Date : Novembre 2026

Support de cours pédagogique — Usage exclusif en laboratoire isolé. Aucune configuration de production, aucun accès Internet pendant les travaux pratiques.
